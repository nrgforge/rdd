## Summary

Defines the product discovery artifact as a single markdown document (./docs/product-discovery.md) with five sections: Stakeholder Map (direct and indirect stakeholders, not personas), Jobs and Mental Models (per-stakeholder jobs and mental models, the primary input for User Mental Model validation), Value Tensions (held as open questions rather than resolved prematurely), Assumption Inversions (output of the Inversion Principle procedural step), and a Product Vocabulary Table (terms in user-facing language with stakeholder attribution). The five sections map to five feed-forward channels: two into MODEL, two into DECIDE, one into ARCHITECT.
