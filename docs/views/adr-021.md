## Summary

Establishes an agent-generates, user-validates model for the Orientation Document: the agent produces ORIENTATION.md as a Pragmatic Action by reading the current Artifact Trail and distilling it into the five-section structure (ADR-020); the user reviews it for accuracy as an indirect test of Authority (Invariant 0); the document is regenerated at natural milestones and on request, with a minimum of after RESEARCH (when only sections 1 and 5 can be populated); and generation and validation iterate to refine the draft. No new epistemic gate is introduced — the document's source artifacts already carry their own gates, so this validation is review-based rather than requiring a new epistemic act.
