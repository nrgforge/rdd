## Summary

Adopts a dual-register naming convention for epistemic gates: 'epistemic gate' remains the precise research/design term used in the domain model, essays, ADRs, and system design, while 'reflection time' is the user-facing term used in skill file text spoken to the user, the README, manifesto, and orientation document. Reflection time IS the epistemic gate, renamed for the audience that experiences it; because the term alone risks under-signaling Invariant 1's generative requirement, skill file authors must pair every instance of 'reflection time' with an immediate generative prompt from the AID cycle (ADR-040).
