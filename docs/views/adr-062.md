**Type:** ADR (index) · **Status:** Proposed · **Canonical source:** `docs/decisions/adr-062-assertion-detection-hook.md`

**Workflow point:** AID cycle Attend phase, at or near artifact-production moments · **Mechanism:** semantic embedded-conclusion detection with open-question reframing

## Summary

Embedded-conclusion detection (user assertions that embed framing, architectural, or design conclusions, with or without confidence markers) is an AID inline observation responsibility rather than a separate UserPromptSubmit pattern-matching hook, because lexical pattern matching was found to be both over-inclusive and under-inclusive. When the agent semantically detects an embedded conclusion near an artifact-production moment, it deploys open-question reframing from the question toolkit. This is a Tier 2 context-responsive mechanism that trades pre-prompt Architectural Isolation for semantic detection, relying on Tier 1 backstops (Susceptibility Snapshot, Framing Audit) to catch what inline detection misses.
