> **Superseded by ADR-040 on 2026-03-30.** ADR-040 replaces the fixed-assignment prompt table with an Attend-Interpret-Decide (AID) cycle. The pedagogical frameworks and prompts defined here remain valid as a candidate library the AID cycle can draw from, but they are no longer a fixed assignment — the agent selects its pedagogical move based on engagement signals, not phase identity. The "5-10 minutes per gate" constraint was replaced by Invariant 4 Amendment 13: "Epistemic cost must be productive, not merely brief."

## Summary

Assigns a primary epistemic act type to each of RDD's five gates: RESEARCH (self-explanation, reflection-on-action, articulation), MODEL (retrieval practice, self-explanation), DECIDE (elaborative interrogation, reflection), ARCHITECT (retrieval practice, articulation, reflection), and BUILD (reflection-in-action, self-explanation). Each gate presents 2-3 prompts, of which the user performs at least one, framed as an invitation to think aloud rather than a quiz, and filled with the specific artifact content and domain vocabulary just produced. Total epistemic cost across a full pipeline is approximately 30-45 minutes, within Invariant 4's 5-10-minute-per-gate constraint.
