## Summary

Adopts five cascading document sizing heuristics — Purpose Test, 3-5 Concept Rule, ~5,000 Word Guideline, Read Contract, and Position-Sensitive Placement, applied in that priority order — as the governing framework for RDD artifact structure. New artifacts (roadmap, field guide) must be designed within these constraints from the start; existing artifacts are evaluated against them but not necessarily split, since decomposing system-design.md requires judgment about its actual access patterns.
