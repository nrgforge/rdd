## Summary

The methodology recognizes two legitimate BUILD patterns: gated mode (the existing canonical per-scenario-group EPISTEMIC GATE pattern) and auto mode (the agent executes the BUILD scope autonomously after high-level direction, with self-administered stewardship). Mode choice is judgment-applied along four axes (mechanical-vs-generative work character, practitioner availability, cycle stakes/reversibility, and stewardship locality — catching vs. teaching), declared per cycle entry as `**BUILD mode:** auto` or `gated` (default gated), settable and shiftable mid-phase by practitioner edit, with no cross-cycle inheritance. Auto mode does not catch design-alternative examination or scoping-judgment surfacing the way gated mode does; the methodology names this cost rather than claiming it away.
