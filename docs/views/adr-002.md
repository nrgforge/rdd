## Summary

Each RDD skill defines its own epistemic gate as a new section in its SKILL.md file, rather than the orchestrator centralizing gate definitions. The orchestrator enforces only the protocol from ADR-001 (every gate must include at least one epistemic act; the user must produce something before advancing) but does not prescribe the specific prompts, so each skill crafts gate prompts tailored to the cognitive demands of its own artifact type (essay, domain model, ADRs, system design, code).
