**Workflow point:** BUILD phase, composition boundaries between build/debug/refactor/review · **Mechanism:** seamless mode shifts with full context inheritance (no re-orientation)

## Summary

Build composes debug, refactor, and review as seamless mode shifts, not dispatched sub-workflows: each mode shift inherits the build session's orientation and current work package with no re-orientation, so skill boundaries are invisible during composition. Debug triggers on unexpected failures (errors unrelated to the current red-phase expectation, previously-passing tests breaking, behavior diverging from orientation); refactor triggers after green or at stewardship across the Three-Level Refactor; review triggers at stewardship checkpoints or on demand. Any skill can also be invoked standalone, running its own Context Gathering, with skill boundaries visible in that mode.
