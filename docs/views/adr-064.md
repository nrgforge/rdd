# ADR-064: Compound Check — PostToolUse(Agent) Dispatch Log + Stop Hook Manifest Verification

[← Overview](overview.md)

**Type:** ADR (index) · **Status:** Updated by ADR-088 · **Cycle:** 10 · **Canonical source:** `docs/decisions/adr-064-compound-check-hooks.md`

**Workflow point:** PostToolUse on every Agent-tool dispatch; Stop hook at session end / phase transition · **Mechanism:** PostToolUse dispatch log cross-referenced with Stop-hook manifest check (compound check)

> **Updated by ADR-088 on 2026-04-27.** ADR-088 amends the Stop hook's manifest check from blocking to advisory across all modes (v0.8.3 release). The compound check mechanism (PostToolUse dispatch log + Stop-hook cross-reference) is retained but its finding is surfaced as advisory rather than as block. The State-C "structurally impossible" claim is amended to "structurally detectable." Skill-text anchoring (ADR-065) is the load-bearing enforcement layer; the Harness Layer adds visibility and detection.

## Summary

Extends ADR-033's hook architecture with two hooks implementing the Harness-Layer compound check: a PostToolUse hook on the Agent tool that logs every Tier 1 subagent dispatch (mechanism, expected output path) to a session-scoped dispatch log, and a Stop hook that cross-references the ADR-063 manifest's required artifacts against that log, distinguishing missing-artifact/no-dispatch (State B), dispatched-but-no-artifact, artifact-without-dispatch (potential State C fabrication), and structural-assertion failures. The compound check makes sophisticated State C fabrication structurally detectable once a `docs/housekeeping/.migration-version` marker places the corpus in enforcement mode; pre-migration corpora run in non-blocking advisory mode. Also introduces the `docs/housekeeping/` directory for infrastructure artifacts under the centered-vs-infrastructure framing, and a non-blocking mtime-based re-audit reminder.
