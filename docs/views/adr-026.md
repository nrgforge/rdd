## Summary

Formalizes Scoped Cycles as a first-class workflow pattern: the RDD pipeline can be constrained to a subsystem or feature, with its own artifact subfolder (e.g., docs/features/auth/), following the same phases and gate protocols as full-project cycles while respecting project-level architectural constraints. Scoped cycles typically end in graduation, folding knowledge into project-level docs; RDD is framed as a deep work tool reached for when a problem warrants structured thinking and set aside once the knowledge is absorbed.
