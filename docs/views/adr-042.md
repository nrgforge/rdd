## Summary

Adds a /rdd-about utility skill that reports the current RDD plugin version from its package metadata, gives a roughly one-paragraph methodology overview in user-facing language ('reflection time', not 'epistemic gate'), and offers to go deeper on any phase, the adaptive-gate philosophy, or how RDD relates to the user's current project, calibrated to whether the user is exploring, committed, or mid-cycle. It is a utility outside the pipeline phases — informational, not procedural — that the orchestrator may offer when it detects a fresh project or an explicit request for orientation.
