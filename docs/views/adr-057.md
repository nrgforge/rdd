# ADR-057: AID Susceptibility Extension with Inline Observation and Isolated Evaluation

**Type:** ADR (index) · **Status:** Proposed · **Canonical source:** `docs/decisions/adr-057-aid-susceptibility-extension.md`

**Workflow point:** AID cycle Attend phase (inline); phase boundaries (isolated evaluation dispatch) · **Mechanism:** inline susceptibility-signal observation with isolated-subagent Susceptibility Snapshot evaluation

## Summary

Extends the AID cycle's Attend phase to notice susceptibility signals (rising assertion density, solution-space narrowing without user initiation, unmodified adoption of agent framing, confidence markers at artifact-production moments, declining engagement with alternatives) without evaluating them inline. Evaluation happens in an isolated context: a specialist subagent reads the observed signals and produces an advisory, non-blocking Susceptibility Snapshot artifact, dispatched at phase boundaries rather than continuously.
