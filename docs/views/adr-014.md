## Summary

Establishes a quality gate applied during the synthesis framing conversation, composed of three tests before committing to the outline: the Davis Test (can the writer name which widely-held assumption the essay denies, using Davis's twelve categories of assumption denial?), the ABT Test (does the essay's central claim fit "Context AND more context, BUT complication, THEREFORE consequence," with a genuinely surprising BUT?), and the Inversion Test (can the claim be stated as the negation of something the target audience currently believes?). If no framing passes all three, the honest and valid outcome is that the cycle did not produce an essay worth writing; this is authorial discipline the agent facilitates but the writer alone decides, not a system gate that blocks or approves.
