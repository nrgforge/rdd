## Summary

When DECIDE writes behavior scenarios for a feature, it also writes preservation scenarios in the same `scenarios.md` block, each asserting an existing observable behavior, contract, or invariant remains unchanged when the feature is exercised, in Given/When/Then form. When the feature genuinely cannot affect existing behavior, the block records a one-line judgment note instead of fabricating a scenario. DECIDE's Step 4 (Behavior Scenarios) is updated to require preservation scenarios for any feature touching existing modules, addressing the DECIDE-phase share of the Einstellung-effect failure chain named in Issue #13.
