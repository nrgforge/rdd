## Summary

Extends ADR-059's Grounding Reframe to fire in a second situation: when a susceptibility snapshot returns a finding that is specific, actionable, and applicable at the current phase boundary, not only when sycophancy risk is unassessable. The protocol body is unchanged — name what's uncertain, offer concrete grounding actions, make the cost of proceeding visible — only the trigger condition is broadened. Two Cycle 10 demonstrations (a DISCOVER per-entry pass correcting six flagged lines in product-discovery.md, and a MODEL belief-mapping check grounding the Invariant 8 commitment) are recorded as canonical examples calibrating what "significant" means.
