## Summary

DECIDE produces (or explicitly identifies within `scenarios.md`) a Cycle Acceptance Criteria Table listing each emergent or aggregate acceptance criterion from product-discovery, recording for each the criterion text, the specified verification layer, the verification method (which scenarios compose to cover it), and a layer-match check (does verification exercise the specified layer or stub it out). BUILD gains Step 5.5 — Cycle Criterion Verification — which writes or identifies an integration test at the stated layer for any entry whose layer-match check is "no." The table is required only when product-discovery names emergent, aggregate, or layer-specifying criteria; cycles with only atomic criteria record a one-line judgment instead.
