## Summary

Operationalizes the Inversion Principle through belief-mapping questions ("What would I need to believe for [the alternative] to be right?") as the primary form, amending ADR-010's cross-cutting application from four locations to six by adding PLAY and SYNTHESIS. The Cycle 9 spike found adversarial framing ("strongest case against X") overcorrected 2-6x by activating Compliance Dynamics, while belief-mapping achieved near-zero preference-driven divergence; adversarial framing is deprecated as the default operationalization but remains available when the user explicitly requests it.
