## Summary

`/rdd-research` gains a five-step research-entry sequence: the user articulates the research question(s) in the research log before any artifact-corpus read; the agent composes a constraint-removal prompt ("what if [the most consequential existing artifact] were not available?") and the user answers; the research-methods-reviewer dispatch (ADR-060) evaluates the combined question set against four criteria (need-vs-artifact framing, embedded conclusions, prior-art treatment, incongruity surfacing); the user revises or accepts flagged issues with rationale; only then does the research loop begin reading the corpus. Per ADR-067's decision procedure the protocol is classified as first-line structural (Skill-Structure Layer) with a cognitive component, not pure Tier 2.
