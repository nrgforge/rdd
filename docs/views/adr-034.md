## Summary

Packages RDD as a Claude Code plugin named rdd under the nrgforge/rdd GitHub repository, using hyphenated skill namespacing (/rdd-research, /rdd-decide, /rdd-build, etc.) rather than the colon separator assumed in earlier drafts. The plugin ships skills/, agents/, hooks/, settings.json, and the ~800KB self-referential artifact corpus together, so the conformance audit's graduation operation can progressively condense process artifacts into reference material over time.
