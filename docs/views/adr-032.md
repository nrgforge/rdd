## Summary

Extracts six specialist subagents from phase skills — citation-auditor, argument-auditor, lit-reviewer, conformance-scanner, orientation-writer, and spike-runner — each with defined input artifacts, output artifacts, and model (mostly sonnet; spike-runner inherits the parent model). Phase skills retain orchestration, epistemic gate conversations, ADR writing, scenario authoring, system design composition, and user interaction; the boundary is that work requiring back-and-forth with the user stays in a skill, while work that reads input artifacts and produces output artifacts becomes a subagent.
