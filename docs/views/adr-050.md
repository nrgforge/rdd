## Summary

In context-reconstructive mode, reconstructed facsimiles (work decomposition and orientation summary always; vocabulary and testable behaviors optionally, for substantial sessions) are written as lightweight markdown files during Context Gathering rather than kept only in conversation. They live in a gitignored `session/` directory, marked with a `session-artifact: true` frontmatter flag, and are explicitly non-permanent and distinct from the RDD artifact trail; after the session the user discards, promotes, or leaves them in place.
