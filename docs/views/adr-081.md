## Summary

The Stop hook detects pre-ADR-078 `cycle-status.md` files (single-entry, no `## Cycle Stack` header) and, within them, pre-ADR-072 entries lacking cycle-shape fields, and applies grandfathered enforcement: advisory-mode manifest checks regardless of the corpus-level `.migration-version` state, until the user runs a new `/rdd-conform` cycle-shape audit scope, manually adds current-schema fields, or graduates the cycle (ADR-025). The audit detects legacy entries, reads and prompts for missing fields, and writes a migrated entry into the current stack format while preserving the existing prose body verbatim. Cycle 8 (rdd-pair) is named as the validation case.
