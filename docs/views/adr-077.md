## Summary

The BUILD skill (and `/rdd-refactor` when extending existing patterns) gains an Applicability Check, a stewardship-checkpoint prompt that fires when an existing pattern is explicitly referenced as the template for new code — the one operative trigger; structural-similarity and stewardship-flag detection are named as aspirational triggers with no current substrate. The check asks four composed questions (name a structural alternative; what's different about the new context; which original-context assumptions carry forward; which fitness properties does system-design.md declare, per ADR-076) and treats the user's substantive response as the load-bearing artifact. It is a Tier 2 conversational mechanism per ADR-058, addressing the BUILD-phase share of the Einstellung-effect failure chain named in Issue #13.
