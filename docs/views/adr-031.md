**Type:** ADR (index) · **Status:** Proposed · **Canonical source:** `docs/decisions/adr-031-artifact-mediated-communication.md`

**Workflow point:** specialist work within any RDD phase · **Mechanism:** artifact-mediated communication: specialist subagents read input artifacts and write output artifacts instead of relying on conversation context

## Summary

Requires specialist work within RDD phases (citation auditing, argument auditing, literature review, conformance scanning) to communicate through artifact files rather than ephemeral conversation context, so findings persist for later review, future-cycle reference, and provenance. This applies to all proposed specialist subagents (citation-auditor, argument-auditor, lit-reviewer, conformance-scanner, orientation-writer, spike-runner); whether the rule is hard or context-dependent is left open, with the initial implementation treating it as a hard rule.
