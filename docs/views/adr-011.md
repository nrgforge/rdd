## Summary

Defines the Product Discovery epistemic gate: it presents 2 prompts drawn from a set of four (self-explanation, elaborative interrogation, retrieval practice, articulation), each filled with the specific stakeholders, jobs, tensions, and inversions from the artifact just produced, following the standard gate protocol of ADR-001. Because the user typically knows more about their own stakeholders than the AI does, the gate's primary function inverts the typical direction: it makes the user's tacit product knowledge explicit for downstream phases rather than testing the user's understanding of AI output.
