## Summary

Adopts the YAML per-phase manifest format from Spike S2 as the canonical Harness-Layer specification for Tier 1 mechanism artifact requirements, living at `hooks/manifests/tier1-phase-manifest.yaml`. Each RDD phase lists required mechanisms with a canonical name, a path template (with `{cycle}` substitution), a byte-size floor, and required headers/fields, which a Stop hook checks against at phase end. The manifest fully catches State B (missing artifact) and trivial State C (thin fabricated stubs) but not sophisticated State C, which requires the compound check specified in ADR-064.
