## Summary

The /rdd-discover skill operates in two modes. Forward mode (greenfield) runs between RESEARCH and MODEL, takes the essay as input, and produces the product discovery artifact (ADR-007) through stakeholder interviews, JTBD analysis, and assumption inversion. Backward mode (existing system) reads existing architecture, ADRs, and domain model to extract implicit product assumptions, validates them against actual user needs, and produces the same five-section artifact plus a Product Debt table (Assumption, Baked Into, Actual User Need, Gap Type, Resolution) that triggers backward propagation through existing invariant-amendment and ADR-supersession infrastructure. The mode is context-determined: backward mode is default when prior RDD artifacts exist, forward mode applies when starting fresh.
