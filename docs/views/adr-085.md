## Summary

Infrastructure artifacts (audits, gates, cycle-status.md, dispatch-log.jsonl, .migration-version, and ADR-050's session/ directory) relocate from `docs/housekeeping/` (ADR-070's placement) to a dotfile `.rdd/` directory at the repository root, so process artifacts are structurally distinguished from product artifacts under `docs/` without hiding them from inspection. Migration runs as a one-shot, idempotent `/rdd-conform migrate-to-rdd` operation that moves files, updates path references across the corpus (skills, hooks, manifests, ORIENTATION.md), and updates `.gitignore`. This partially supersedes ADR-070 (IETF Updates analog): ADR-070's centered-vs-infrastructure framing and migration mechanics remain current authority; only the directory placement changes.
