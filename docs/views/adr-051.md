## Summary

In context-reconstructive mode, the build skill derives work packages during Context Gathering from the ticket, codebase exploration, and Context Gathering breadcrumbs, using the roadmap's structural conventions: each package specifies scope, integration points, testable behaviors, dependencies classified as hard/implied/open, and an optional demo scenario. The user validates the decomposition before it is written as a reconstructed facsimile; the decomposition is approximate and user-validated, not architecturally authoritative like a roadmap-derived work package.
