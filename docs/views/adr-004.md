## Summary

The user's epistemic act responses at each gate become available as context for the next phase: in single-session RDD cycles the responses are already in conversation history, while for multi-session cycles the orchestrator instructs the AI to read prior gate responses when loading context for a new phase. No storage format is prescribed; the orchestrator's status table can summarize key responses at session resumption. Subsequent phases should attend to the user's stated understanding and emphasis, not just the formal artifacts, activating Invariant 7's bidirectional mechanism.
