## Summary

`.rdd/cycle-status.md` gains two optional fields the Stop hook honors: `**Skipped phases:**`, a comma-separated list of phases the current cycle does not run, which the hook treats as having no required manifest artifacts; and `**Paused:**`, a dated line marking the cycle deliberately dormant, which short-circuits all per-phase manifest checks to allow. A new Pause Log section in cycle-status.md records each pause/resume event so the state stays visible rather than silent, preserving Invariant 8. The fields close a Stop-hook infinite-loop failure mode observed in Cycle 015 for mini-cycles (Mode D) and user-away sessions during an in-progress gate.
