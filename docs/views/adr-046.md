## Summary

The `/rdd-review` skill integrates with the build phase as an optional enhancement to stewardship checkpoints: after a Tier 1 stewardship check completes at scenario group boundaries, the build skill may invoke `/rdd-review` in corpus-grounded mode to add epistemic review alongside architectural conformance. Reviewing each work package during build is the expected rhythm but not mandatory; outside build, the review skill operates independently with no stewardship connection.
