## Summary

Context-reconstructive review begins with a five-step collaborative context-gathering step: the reviewer provides pointers (ticket URLs, MR links, docs, discussion threads); the agent fetches and reads them with whatever tools are available; the agent synthesizes a brief orientation summary; the reviewer validates or corrects it, triggering re-synthesis if the correction is substantial; and only then does the agent surface review questions from the validated orientation.
