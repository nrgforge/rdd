## Summary

Adds a Roadmap document as a Tier 2 artifact containing work packages (derived from the system design's module decomposition), dependencies classified as hard dependency, implied logic, or open choice, transition states (coherent intermediate architectures), and open decision points — explicitly excluding detailed task lists, timelines, or single-commit prescriptions, so developers own their own sequencing decisions. The roadmap is a pragmatic artifact (Invariant 3): agent-generated from the system design and ADRs within the ARCHITECT phase, user-validated, and updated reflexively; no epistemic gate is introduced because it is generated within an existing phase, not at a new phase transition.
