## Summary

Structures the synthesis conversation into three phases after agent pre-work. Pre-conversation Artifact Trail Mining applies five novelty signals (explicit surprise statements, reframing events, assumption denials, negative case integrations, superseded decisions) to rank candidate discoveries. Phase 1 Journey Review walks the trail chronologically while the user recalls and articulates what happened; Phase 2 Novelty Surfacing has the user react to ranked candidates; Phase 3 Framing Conversation has agent and user co-produce the essay's central question, volta, and structural form using narrative frameworks as optional lenses. The outline is the deliverable and must be a springboard: non-formulaic, pre-populated with citations extracted from the research log and essays, and run through a citation audit (via /citation-audit) before finalizing, so no hallucinated source reaches the writer.
