## Summary

Default audit round count is 3; round 4 fires only when the Convergence-Saturation Signal (R3: P1 = 0, P2-new ≤ 1, no new framings) has not triggered; round 5 only if R4 surfaces a new P1; rounds beyond 5 need explicit practitioner authorization. A structured verdict line closes each round. Form-change events reset the round-count baseline (the first audit on a new form is its R1). Skill-Structure Layer in argument-auditor.md and citation-auditor.md.
