## Summary

Gives /rdd-review two operating modes selected by context: corpus-grounded review, invoked within an RDD project and scoped to a work package, which reads relevant ADRs, scenarios, domain model, and system design to synthesize orientation and ground review questions in the provenance chain; and context-reconstructive review (RDD-lite), invoked outside an RDD corpus, which gathers breadcrumbs (ticket URLs, MR links, doc pointers, discussion threads) from the reviewer and performs lightweight discovery to reconstruct orientation before surfacing questions. Mode is detected automatically — corpus-grounded when RDD artifacts exist and cover the work package in scope, falling back to context-reconstructive for uncovered areas — but the user can override in either direction.
