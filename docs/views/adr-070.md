## Summary

Specifies the mechanical migration of `docs/housekeeping/audits/` and `docs/housekeeping/cycle-status.md` into the housekeeping directory structure that ADR-064 committed to but deferred, creates `docs/housekeeping/gates/` for ADR-066's gate reflection notes, and updates path references across ADRs, essays, skill files, the ADR-063 manifest, the domain model, and ORIENTATION. The migration is a one-shot, idempotent operation triggered by `/rdd-conform migrate`, writing a `.migration-version` marker file that the Stop hook (ADR-064) reads to distinguish advisory mode (pre-migration) from enforcement mode (migrated). `rdd-conform` gains three new audit scopes: housekeeping directory organization, gate reflection note template alignment, and dispatch prompt format.
