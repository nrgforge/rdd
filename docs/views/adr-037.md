## Summary

Adds Interaction Specifications as a DECIDE-phase artifact at docs/interaction-specs.md, written after scenarios and derived from Product Discovery's stakeholder models, specifying how each stakeholder works with the system at the workflow level — more concrete than scenarios, more stable than implementation details, organized by stakeholder with Super-Objective, Task, and Interaction mechanics fields. The derivation method from stakeholder model to task decomposition is left as an open design problem that evolves through use; the artifact should stay thin, per Invariant 4.
