## Summary

Adds a Conformance Audit mechanism with four operations: audit (gap analysis against the current skill version, using structural-vs-format severity), remediation (auto-generate structural gaps, flag format gaps for the user), drift detection (a best-effort semantic sweep comparing artifacts against implementation), and graduation (fold RDD knowledge into native project docs and archive RDD artifacts, recurring at the subsystem level, not a one-time exit). All four operations are pragmatic actions: the audit produces a report and the user decides what to act on.
