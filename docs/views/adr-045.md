## Summary

Makes review questions the primary output of /rdd-review — questions grounded in orientation context that a thoughtful senior reviewer would ask, meant to guide the reviewer's own analysis rather than hand them a verdict — with mechanical findings (missing type checks, circular dependencies, obvious bugs, style violations) surfaced separately and without severity ratings, since those require no judgment to identify. The skill produces no merge verdict, no severity-categorized issue list, and no AI-authored comments for the reviewer to post as their own; the number of questions adapts to the reviewer's stated time budget, and the classification test is whether an issue can be verified without knowledge of intent, context, or system history (mechanical) or requires the reviewer's recognition-primed judgment (a question).
