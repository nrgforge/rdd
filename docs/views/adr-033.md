## Summary

Implements five cross-cutting concerns as hooks in hooks/hooks.json at the plugin level, since plugin-provided agents cannot define hooks in their own frontmatter: an invariant reminder (PreToolUse on Write/Edit under docs/), an epistemic gate enforcer (Stop), a skill activator (UserPromptSubmit), an orientation trigger (PostToolUse on key artifacts), and a document sizing check (PostToolUse on docs/). The epistemic gate enforcer uses reminder injection rather than blocking, since a blocking Stop hook would prevent the agent from completing at all rather than resuming the phase.
