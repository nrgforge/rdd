## Summary

RDD adopts precondition composition as the scope-adaptive enforcement pattern. `tier1-phase-manifest.yaml` per-phase entries gain an optional `applicable_when` block listing conditions (initial primitives: `cycle_type_in`, `cycle_type_not_in`, `phase_not_skipped`, `parent_cycle_present`, `parent_cycle_absent`); when any condition is unmet, the hook skips the check with `onFail: CONTINUE` semantics and records the skip in the dispatch log. Existing manifest entries without `applicable_when` continue to fire unconditionally, so standard full-pipeline cycles are unaffected. Preconditions cannot skip the compound check (ADR-064) for dispatches that already fired.
