## Summary

`docs/cycle-status.md` adopts a stack-based multi-cycle schema: a `## Cycle Stack` section holding `### Active:` and `### Paused:` entries, top of stack being the active cycle. Each entry carries per-cycle fields (cycle number, started date, current phase, cycle type, parent cycle, ADR-072's skipped-phases and paused fields, phase-at-pause, spawned-by). Spawning a nested cycle pauses the outer cycle by default (`pause-parent`) or, when explicitly declared with a `**Continue-parent rationale:**`, runs concurrently (`continue-parent`) with the outer cycle's enforcement suspended while the inner cycle is on top. The Stop hook reads only the top-of-stack entry; legacy single-entry cycle-status.md files are treated as a one-entry stack.
