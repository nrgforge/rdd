## Summary

Ships a UserPromptSubmit hook (the skill activator) that detects explicit RDD-workflow requests and injects context telling the agent to proceed directly to the requested phase, because RDD research already serves as the brainstorming/exploration step that the superpowers plugin would otherwise intercept for. This is the interim, self-contained fix; the durable fix proposed alongside it is an upstream superpowers rule that an explicitly named workflow request overrides the brainstorm-first default for any plugin with its own exploration phase.
