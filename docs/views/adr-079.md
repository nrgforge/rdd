# ADR-079: Non-Interrupting Stop Predicate for In-Progress Gate Conversations

**Type:** ADR (index) · **Status:** Proposed · **Cycle:** 016 · **Canonical source:** `docs/decisions/adr-079-non-interrupting-stop-predicate.md`

## Summary

The active cycle entry gains a `**In-progress gate:**` field (e.g., `decide → architect`) that the orchestrator sets at the start of an AID phase-boundary gate and clears when the gate-reflection note is written. While the field is set, the Stop hook returns allow without running the gate-reflection-note check for that named boundary, while other manifest checks for the source phase, and the compound check (ADR-064) for any dispatch that fires, continue to run. If the orchestrator fails to set the field the hook reverts to its existing blocking behavior (safe failure); if it fails to clear the field the note check is silently skipped, mitigated by a per-session advisory notice and a `/rdd-conform` heuristic.
