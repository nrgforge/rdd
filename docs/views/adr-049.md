## Summary

Context Gathering is an embedded protocol, not a separate invocable skill. A five-step protocol (detect mode, prompt for breadcrumbs, fetch and read, synthesize orientation, validate with the user) is specified once in a shared reference section and each of the four Composable Skill Family skills' SKILL.md implements it, adapting step 4 (synthesize orientation) to its own downstream needs. User validation (step 5) automates fetching and synthesis while keeping the user's confirmation as the epistemic boundary.
