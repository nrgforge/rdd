**Workflow point:** BUILD phase, skill-family architecture · **Mechanism:** decomposition into four composable skills sharing embedded Context Gathering

## Summary

Decomposes the monolithic build skill into four composable skills sharing a Context Gathering foundation: `/rdd-build` (the outer TDD loop, composing the other three), `/rdd-debug`, `/rdd-refactor`, and the pre-existing `/rdd-review`. Each skill operates in both pipeline mode (full artifact corpus) and context-reconstructive mode (orientation from heterogeneous sources), and can be used standalone or composed within a build cycle.
